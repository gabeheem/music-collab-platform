# GitMusic

A music collaboration project with saved versions, branches, and published tracks.

| Part | Technology |
| --- | --- |
| Frontend | Angular and TypeScript |
| Backend | Python and FastAPI |
| Database (planned) | PostgreSQL through Supabase |
| Accounts (planned) | Supabase Auth |
| Version control | Git and GitHub |

See [backend setup](backend/README.md) to run the API and [the project plan](docs/requirements/project-plan.md) for requirements and the build order.
The backend currently has a health endpoint. Login, uploads, version history,
and publishing still need to be built.
